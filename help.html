🎮 匿名猜拳淘汰賽

網站使用說明

🙋 參賽者加入

1️⃣ 點房主分享的邀請連結
2️⃣ 輸入匿名暱稱
3️⃣ 加入遊戲
4️⃣ 等待房主停止加入並開始淘汰賽
5️⃣ 畫面解鎖後選擇 ✊ ✌️ 🖐️

👑 房主流程

建立遊戲 → 分享連結 → 🔒 結束加入 → 選擇淘汰規則 → ▶️ 開始淘汰賽 → 🛑 結束本輪

房主不參與猜拳。

🎯 淘汰規則

房主在整場淘汰賽開始前選擇一次：

🏆 贏的人晉級：正常猜拳，勝方留下。

😈 輸的人晉級：反向玩法，敗方留下。

按下「開始淘汰賽」後規則鎖定，後面的分組與下一輪都沿用同一規則。

✊✌️🖐️ 猜拳

✊ 石頭勝 ✌️ 剪刀
✌️ 剪刀勝 🖐️ 布
🖐️ 布勝 ✊ 石頭

同一輪全部同拳，或三種拳都有，視為平手。

👥 第一輪分組

第一輪結束後，房主可選擇依第一輪出拳分成石頭組、剪刀組、布組，再自行決定哪一組先比。

沒輪到的組別只是暫時觀賽，不代表被淘汰。只有 1 人的組別會自動晉級。

👀 淘汰與聊天

淘汰後不能再出拳，但仍可觀看比賽與使用房間討論區。每則訊息最多 100 字。

🏆 結束

全場只剩 1 位參賽者時，系統會結束比賽並顯示最後留下的人。

⚠️ 注意

房主按「結束加入」後，新玩家不能再加入；已加入者仍可繼續。遊戲使用 GitHub Pages + Firebase，因此房主電腦不必一直開著。
